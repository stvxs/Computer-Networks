# 8. Решение задач

## Условия

### Задача 1

Нужно получить 5 подсетей, в каждой из которых должно быть не менее 25 хостов.

- Сеть: `192.168.0.0/24`
- Определить маску, количество подсетей и количество хостов.

### Задача 2

Разделить сеть `192.168.50.0/24` на 6 подсетей.

- Определить маску.
- Определить количество хостов.
- Указать диапазоны подсетей.

---

## Решение задачи 1

### 1. Подбор маски

Используем формулу:

`2^h - 2 >= 25`

При 5 битах для хостов:

`2^5 - 2 = 30`

Оставляем 5 бит для хостов и 27 бит для сети.

**Маска: `/27` - `255.255.255.224`.**

### 2. Расчёт маски

В одном октете 8 бит. Для маски `/27` в последнем октете остаётся 3 единицы и 5 нулей.

Двоичная запись последнего октета:

`11100000`

Значения битов:

| Бит | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Значение | 1 | 1 | 1 | 0 | 0 | 0 | 0 | 0 |

Последний октет:

`128 + 64 + 32 = 224`

Полная маска:

`255.255.255.224`

Шаг подсети:

`256 - 224 = 32`

### 3. Количество подсетей

Исходная маска - `/24`, новая маска - `/27`.

Количество дополнительных бит:

`27 - 24 = 3`

Количество подсетей:

`2^3 = 8`

Получаем 8 возможных подсетей, из которых требуются 5.

### 4. Количество хостов

Для хостов остаётся 5 бит.

`2^5 - 2 = 30`

В каждой подсети доступно 30 хостов.

### 5. Диапазоны подсетей

| № | Адрес сети | Диапазон хостов | Broadcast |
|---|---|---|---|
| 1 | `192.168.0.0/27` | `192.168.0.1-192.168.0.30` | `192.168.0.31` |
| 2 | `192.168.0.32/27` | `192.168.0.33-192.168.0.62` | `192.168.0.63` |
| 3 | `192.168.0.64/27` | `192.168.0.65-192.168.0.94` | `192.168.0.95` |
| 4 | `192.168.0.96/27` | `192.168.0.97-192.168.0.126` | `192.168.0.127` |
| 5 | `192.168.0.128/27` | `192.168.0.129-192.168.0.158` | `192.168.0.159` |

**Результат задачи 1:**

- Маска: `/27` (`255.255.255.224`).
- Количество возможных подсетей: 8.
- Требуется подсетей: 5.
- Доступных хостов в каждой подсети: 30.

## Решение задачи 2

### 1. Подбор маски

Необходимо разделить сеть на 6 подсетей.

Используем формулу:

`2^n >= 6`

При 3 дополнительных битах:

`2^3 = 8`

Получаем 8 возможных подсетей, чего достаточно для выполнения задания.

Новая длина префикса:

`24 + 3 = 27`

**Маска: `/27` - `255.255.255.224`.**

### 2. Расчёт маски

Двоичная запись маски:

`11111111.11111111.11111111.11100000`

Последний октет:

`128 + 64 + 32 = 224`

Полная маска:

`255.255.255.224`

Шаг подсети:

`256 - 224 = 32`

### 3. Количество хостов

При маске `/27` остаётся 5 бит для хостов.

`2^5 - 2 = 30`

В каждой подсети доступно 30 хостов.

### 4. Диапазоны подсетей

| № | Адрес сети | Диапазон хостов | Broadcast |
|---|---|---|---|
| 1 | `192.168.50.0/27` | `192.168.50.1-192.168.50.30` | `192.168.50.31` |
| 2 | `192.168.50.32/27` | `192.168.50.33-192.168.50.62` | `192.168.50.63` |
| 3 | `192.168.50.64/27` | `192.168.50.65-192.168.50.94` | `192.168.50.95` |
| 4 | `192.168.50.96/27` | `192.168.50.97-192.168.50.126` | `192.168.50.127` |
| 5 | `192.168.50.128/27` | `192.168.50.129-192.168.50.158` | `192.168.50.159` |
| 6 | `192.168.50.160/27` | `192.168.50.161-192.168.50.190` | `192.168.50.191` |

Оставшиеся две подсети:

- `192.168.50.192/27`
- `192.168.50.224/27`

**Результат задачи 2:**

- Маска: `/27` (`255.255.255.224`).
- Количество возможных подсетей: 8.
- Требуется подсетей: 6.
- Доступных хостов в каждой подсети: 30.
